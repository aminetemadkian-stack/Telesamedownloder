# TeleStream Downloader & Hub (تله‌استریم هاب)

یک اپلیکیشن مدرن اندرویدی ساخته شده با **Kotlin** و **Jetpack Compose** برای مدیریت، پخش جریانی و دانلود ویدیوها و رسانه‌ها به همراه سیستم مدیریت پروکسی هوشمند، دسته‌بندی پلی‌لیست‌ها و مدیریت بهینه حافظه ذخیره‌سازی.

---

## 🚀 ویژگی‌های کلیدی (Features)

- **رابط کاربری مدرن با Material Design 3:** طراحی متریال ۳، بهینه‌سازی‌شده برای تمامی اندازه‌های صفحه (گوشی و تبلت‌هایی نظیر Galaxy Tab).
- **دانلودر چندبخشی و پایدار:** امکان دانلود موازی فایل‌ها، توقف و ادامه دانلود (Pause/Resume).
- **مدیریت پروکسی و ضد تحریم:** پشتیبانی از پروکسی‌های اختصاصی (MTProto, SOCKS5, HTTP) برای دور زدن محدودیت‌های شبکه.
- **پلیر داخلی و پیش‌نمایش رسانه:** پخش روان بدون نیاز به پلیر خارجی با بافرینگ بهینه.
- **مدیریت هوشمند حافظه (Smart Storage Manager):** پاک‌سازی خودکار و پایش فضای دیسک با استفاده از کش هوشمند (LRU Cache).
- **پایگاه داده آفلاین Room:** ذخیره‌سازی پایدار پلی‌لیست‌ها، تاریخچه و رسانه‌ها به صورت محلی.

---

## 🛠 پیش‌نیازها و فناوری‌های استفاده‌شده (Tech Stack)

- **زبان:** Kotlin
- **چارچوب کاربری:** Jetpack Compose با Material 3
- **معماری:** MVVM + Clean Architecture + StateFlow
- **پایگاه داده:** Room Database + KSP
- **شبکه و وب:** Retrofit, OkHttp, Moshi
- **لودر تصویر:** Coil Compose
- **ورژن ابزار بیلد:** Android Gradle Plugin (AGP 9.1+)
- **سازگاری SDK:** 
  - `minSdk = 24` (Android 7.0+)
  - `compileSdk = 35`
  - `targetSdk = 35`

## ⚙️ نحوه اجرا و راه‌اندازی (Build & Setup)

### ۱. کلون کردن ریپازیتوری
```bash
git clone https://github.com/aminetemadkian-stack/Telesamedownloder.git
cd Telesamedownloder
```

### ۲. پیکربندی کلیدها (`.env`)
فایل `.env` در ریشه پروژه قرار دارد. در صورت نیاز به استفاده از مدل‌های هوش مصنوعی Gemini، کلید خود را درون آن قرار دهید:
```properties
GEMINI_API_KEY=your_api_key_here
```

### ۳. باز کردن در Android Studio
1. نرم‌افزار **Android Studio** را باز کنید.
2. گزینه **Open** را انتخاب کرده و پوشه پروژه را انتخاب نمایید.
3. اجازه دهید Gradle به‌صورت خودکار وابستگی‌ها را دانلود و پروژه را Sync کند.

### ۴. ساخت فایل نصبی APK (از طریق ترمینال)
برای ساخت فایل APK دیباگ:
```powershell
.\gradlew assembleDebug --no-configuration-cache
```
فایل نهایی در مسیر زیر تولید می‌شود:
```
app/build/outputs/apk/debug/app-debug.apk
```

## 🛡️ تغییرات اخیر و رفع باگ‌ها (Recent Fixes)

- **حل خطای `android-36.1`:** کاهش نسخه ناپایدار `core-ktx` از `1.18.0` به نسخه پایدار `1.15.0` و تنظیم `compileSdk` و `targetSdk` بر روی `35`.
- **حل مشکل حلقه کرش و پیام ریلود تبلت‌های سامسونگ:**
  - انتقال ایمن سازنده ViewModel به Activity (`by viewModels()`).
  - ایمن‌سازی کامل متدهای راه‌اندازی در بلاک `init` با `try-catch` برای خواندن فایل‌ها و وضعیت ذخیره‌سازی دیسک (`StatFs`).
- **حذف امضای دستی دیباگ:** حذف خط `signingConfig = signingConfigs.getByName("debugConfig")` تا گریدل بدون تداخل با کی‌استور پیش‌فرض سیستم بیلد کند.
- **حذف خطای وابستگی فایربیس:** حذف وابستگی‌های اعلان‌نشده `firebase-appcheck` در گریدل.
